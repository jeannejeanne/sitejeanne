# sitejeanne

Mon premier site web, fait en HTML, CSS et JavaScript.

## Les fichiers

- `index.html` : le **contenu** de la page (textes, titres, boutons)
- `style.css` : l'**apparence** (couleurs, tailles, mise en page)
- `script.js` : l'**interactivité** (ce qui se passe quand on clique)

## Voir le site

Double-clique sur `index.html` : il s'ouvre dans ton navigateur.

## Idées pour t'entraîner

1. Change les textes dans `index.html` pour parler de toi.
2. Change la couleur `--principale` en haut de `style.css`.
3. Ajoute une nouvelle carte dans la section « Mes passions ».
4. Ajoute tes propres messages dans la liste `messages` de `script.js`.
